Mijn Homelab

Mijn eigen private cloud en speeltuin

Van hobby naar volwaardige infrastructuur

Het begon met een Raspberry Pi om mee te experimenteren, allemaal Linux packages installeren (zonder te weten wat het allemaal deed) en er kwamen verschillende applicaties bij. Van Bitwarden tot PiHole.

Later werd dit een Mini PC met daarop Proxmox om virtuale machines op te draaien. Met behulp van Docker kon ik gemakkelijk en snel applicaties aanmaken (en ook weer makkelijk afbreken of aanpassen).

Automatiseringen: GitHub & Komodo

In het begin was het redelijk makkelijk, een paar apps en één Raspberry Pi, een keer in de week alles updaten en we kunnen weer vooruit. Maar hoe erger de hobby werd, hoe meer tijd het kostte om alles bij te houden. Daarom ben ik begonnen met het automatiseren van een hoop taken.

Zo krijg ik realtime update meldingen via GitHub wanneer er een nieuwe versie van een applicatie beschikbaar is. Met behulp van Komodo kan ik vervolgens met één druk op de knop de applicatie updaten, zonder dat ik in hoef te loggen op de servers. Als er iets misgaat kan ik gemakkelijk terug door de vorige versie te herstellen.

Mocht het echt heel goed misgegaan zijn, kan ik altijd nog terugvallen op de backups en snapshots die Proxmox automatisch maakt van alle virtuele machines. Natuurlijk op een ander device dan Proxmox zelf én offsite naar een Azure Storage Account. Zo kan ik altijd terug naar een werkende situatie.

Monitoring: Grafana & Uptime Kuma

Om ervoor te zorgen dat ik een SLA kan behalen van ongeveer 99.9% uptime, heb ik monitoring toegevoegd met behulp van Uptime Kuma en Grafana. Uptime Kuma houdt de beschikbaarheid van alle apps in de gaten, terwijl ik vanuit Grafana diepgaande logging en metrieken kan bekijken.
